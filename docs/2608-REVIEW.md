### 프롬프트 3 - 온보딩 완료 여부 가드 추가

```text
로그인한 사용자가 온보딩을 끝냈는지 확인한 뒤 대시보드 접근을 허용하도록 수정해줘.

목표:
- 로그인하지 않은 사용자는 로그인 화면으로 이동
- 로그인했지만 프로필이 없는 사용자는 온보딩 화면으로 이동
- 프로필이 있는 사용자는 대시보드 접근 허용

조건:
- 로딩 중에는 빈 화면 대신 로딩 상태를 보여줘.
- 무한 이동이 생기지 않게 라우팅 조건을 정리해줘.
- 수정 후 `npm run build`로 확인해줘.
```

### 프롬프트 4 - CSV 분석 최소 기능 추가

```text
랜딩에서 말하는 광고 분석 기능이 제품 안에서도 보이도록 CSV 업로드 최소 기능을 추가해줘.

목표:
- 대시보드 또는 분석 페이지에서 CSV 파일을 선택할 수 있게 해줘.
- 업로드한 CSV의 행 수와 주요 컬럼명을 화면에 보여줘.
- 숫자 컬럼이 있으면 합계 또는 평균 중 하나를 보여줘.
- 파일 형식이 맞지 않으면 짧은 오류 메시지를 보여줘.

조건:
- 서버 저장 없이 브라우저 안에서 먼저 처리해도 돼.
- 큰 기능으로 확장하지 말고 week_04 배포에 맞는 최소 범위로 구현해줘.
- 수정 후 `npm run build`, `npm run lint`로 확인해줘.
```
